Privacy Policy

This policy covers contedevie-uploader, the private automation tool behind the Conte de Vie YouTube channel.

Who uses this application

Only the channel owner. The application has no public sign-up, no other users, and no shared interface. It authenticates as a single Google Account — the one that owns the YouTube channel — and acts on that account alone.

What data it accesses

The application requests one Google permission: https://www.googleapis.com/auth/youtube.upload. That permission is used for exactly one purpose: uploading the owner's own video files to the owner's own YouTube channel.

The application does not read viewer data, comments, subscriber lists, analytics, contacts, email, files, or any other Google service.

What data it stores

An OAuth token for the owner's account, held as an encrypted secret in the owner's own private GitHub repository, and a small local database recording which videos have already been published so the same one is not posted twice. Video files exist only for the seconds between download and upload on a temporary build machine, and are discarded when the job ends.

What it does not do

No data is sold, rented, shared with third parties, used for advertising, or used to train models. There is no analytics or tracking on this website.

Retention and deletion

The owner can revoke the application's access at any time at myaccount.google.com/permissions, which immediately and permanently ends its ability to access the account. Stored tokens and records can be deleted by the owner at any time.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
